# Backlog

There is one file per epic (`E0.md` … `E13.md`). Each file mirrors `../mvp-plan.md` §8.

- The sprint plan is in `../mvp-plan.md` §9.
- Each ticket carries an ID, a title, and its priority, complexity and dependencies. It also has a description, acceptance criteria (AC) and technical notes (TN).
- The global Definition of Done is in `../definition-of-done.md`.

Track a ticket's status by adding `**Status:** Todo | In progress | Done (PR #)` under its heading. The files are written so they can be synced to JIRA later.

**Since Sprint 0, these files are the source of truth for ticket content and status.** `mvp-plan.md` §8 is the original snapshot. Edit tickets here, and don't regenerate these files from the plan, because that would erase the status lines.
