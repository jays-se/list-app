# E12 Hardening and release

> Mirrors docs/mvp-plan.md §8. Global Definition of Done: docs/definition-of-done.md. Format: ID · Title · Priority · Complexity · Deps.

- **E12-S1 · Observability** · P0 · M · Deps: E2-S1, E1-S5
  - **Status:** Done (Sprint 6, ADR-0025).
    - An in-house Prometheus endpoint at `/metrics`: HTTP count and latency by route, outbox backlog, failed and oldest-pending events, client errors, and rate-limited requests.
    - Worker and main-thread errors go through the `error.report` command to `POST /client-errors`, deduplicated and capped.
    - **Deferred:** the OTel SDK and traces, until a collector exists.
  - Description: OTel dashboards and error reporting from the worker and main thread.
- **E12-S2 · Security review** · P0 · M · Deps: all P0 stories
  - Scope: CSP, rate limits, tenant-isolation tests, dependency audit, threat model.
  - **Status:** Done (Sprint 6).
    - `docs/security.md` has the threat model (T1–T12).
    - Per-IP token buckets (on in prod) cover sign-in, bulk create, uploads and client errors.
    - CI runs `pnpm audit --prod` and `govulncheck`. It found GO-2026-5970 (`golang.org/x/text` v0.29.0, pulled in by pgx), which was upgraded to v0.39.0.
    - The XSS corpus found an href quoting gap, now fixed.
- **E12-S3 · a11y and perf budgets** · P1 · M
  - Targets: axe checks in e2e, keyboard-only flows, main bundle under 150 KB gzipped, INP under 200 ms.
  - **Status:** Done, except INP. `check:bundle` in CI and in the web image enforces entry ≤ 150 KB (currently 120.6), worker ≤ 60 KB (22.3) and CSS ≤ 20 KB (9.5). Axe runs on every main page, and there is a keyboard-only task e2e. **Not measured:** INP (no field data yet).
- **E12-S4 · Single-host deploy (compose) and release checklist** · P0 · M · Deps: E0-S3, E0-S4
  - Description: CI publishes versioned images. `deploy/compose.prod.yml` adds TLS through Caddy, a migrations one-shot container, nightly backups with a restore drill, and a release checklist. No cloud-provider services (ADR-0013).
  - Description: migrations job and release checklist.
  - **Status:** Done (Sprint 6), not yet exercised on a host.
    - `deploy/compose.prod.yml` runs Caddy with TLS and HSTS, versioned GHCR images (web and api, published on `v*` tags), a one-shot migrate container, and nightly `pg_dump` plus a blob archive with 14-day retention.
    - `deploy/.env.example` lists the settings; `docs/release.md` has the checklist, rollback, restore drill and alerts.
    - Blobs use the local driver on a volume (same-origin, no CSP change); MinIO is optional.
