# E11 Docs (markdown)

> Mirrors docs/mvp-plan.md §8. Global Definition of Done: docs/definition-of-done.md. Format: ID · Title · Priority · Complexity · Deps.

- **E11-S1 · Docs API** · P1 · M · Deps: E2-S5
  - **Status:** Done (Sprint 6, ADR-0025).
    - `/docs` supports CRUD with If-Match (428 and 409) and a client link.
    - `doc_files` allows up to 10 files per doc, each up to 20 MB, via presigned uploads.
    - Any member edits; the creator or a workspace OWNER deletes.
    - Upload-as-doc runs in the worker: .md and .txt become the doc's content; other files are attached.
    - Clients gain `docCount`, and client detail lists linked docs.
  - Endpoints: CRUD, upload-as-doc (20 MB), attachments, client link.
- **E11-S2 · Docs list and editor** · P1 · L · Deps: E11-S1
  - Description: a textarea editor; the worker debounces autosave and renders markdown to a safe AST.
  - AC: XSS test corpus passes; there is a saving/saved indicator; the user is warned when leaving before a save finishes.
  - **Status:** Done (Sprint 6).
    - The in-house parser produces a safe AST (`docs/markdown.ts`); the XSS corpus has 17 cases.
    - The textarea editor is uncontrolled and keyed by `editorKey`, with a live preview.
    - The worker autosaves after 800 ms, coalesces edits, and shows save states `saved`/`unsaved`/`saving`/`error`/`conflict`, with "Reload latest" on a conflict.
    - `useBlocker` and `beforeunload` guard against leaving with unsaved changes.
    - Doc files support upload progress.
