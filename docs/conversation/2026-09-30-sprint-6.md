## Decisions

| Decision | Why | Recorded in |
|---|---|---|
| Doc files live in their own `doc_files` table and reuse the attachment schemas and upload code | Keeps the task attachment rules (5×5 MB, task permissions) separate from docs (10×20 MB, any member); the worker's upload path is unchanged | ADR-0025 |
| Any member edits any doc; the creator or a workspace OWNER deletes | Matches the reference app (no per-doc sharing) | ADR-0025 |
| Upload-as-doc runs in the worker (.md and .txt become content; other files are attached) | No extra endpoint, and the file is read off the main thread | ADR-0025 |
| In-house markdown parser to a safe AST; links only http(s) or mailto with no quotes or brackets | ADR-0011's minimal dependencies; the XSS corpus caught a quote left in an href | `markdown.ts` and its tests |
| Autosave in the worker (800 ms). The editor is uncontrolled and keyed by `editorKey`, and a local draft stays authoritative once edited here | No lost keystrokes or cursor jumps; a teammate's edit shows up as a conflict with "Reload latest" rather than silently replacing text | `docs.actions.ts` |
| No OTel SDK yet: in-house Prometheus `/metrics` plus client error reporting | No collector without a cloud service; about 40 fewer modules | ADR-0025 |
| Rate limits are per-IP token buckets, on by default only in prod | e2e and flow tests sign in many users from one address | ADR-0025, config |
| Prod blobs use the local driver on a volume, not MinIO | Same-origin presigned uploads need no CSP or subdomain change, and backup is simpler on one host | ADR-0025, `compose.prod.yml` |
| Upgraded `golang.org/x/text` from v0.29.0 to v0.39.0 | govulncheck: GO-2026-5970 (an infinite loop on invalid input) | `docs/security.md` T10 |
