## Delivered
- **Frontend data plane:**
  - `@app/protocol`
  - `@app/query` (in-house, runs in the worker)
  - `@app/api-client`
  - `@app/domain` (`system.info` view)

  - tokens with light, dark and HC themes
  - 9 primitives and in-house icons
  - a `/_design` gallery
- **Web app:** `apps/web`, with react-router 8, an app shell, a theme switcher, a home page backed by the live worker view, and error pages.
- **API:** `apps/api` in Go:
  - config, logging, middleware
  - problem+json responses
  - health and readiness endpoints
  - `system/info`
  - graceful shutdown
  - migrations with row-level security
  - Dockerfile
- **Contract:** `api/openapi.yaml` v0 plus a route↔contract test.
- **CI and tooling:** CI workflow, git hooks, boundary checker, and the three pattern skills (`add-worker-view`, `add-ui-component`, `add-db-migration`).
