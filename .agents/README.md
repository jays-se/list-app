# .agents: tool-independent rules and skills

This folder is the only place rules and skills are written. Claude Code, Cursor, Codex and any future tool all read the same content (ADR-0015).

```
.agents/
  rules/<name>.md          # frontmatter: description (required), paths (optional list of globs)
  skills/<name>/SKILL.md   # frontmatter: name, description
```

## Add or change a rule
1. Create or edit `.agents/rules/<name>.md`:
   ```md
   ---
   description: One line explaining when this rule matters.
   paths:
     - "apps/web/**/*.tsx"
   ---
   Rule body…
   ```
   Leave out `paths` to make the rule always apply. Don't use brace globs such as `{ts,tsx}`; list each pattern separately instead.
2. Run `node scripts/sync-agents.mjs`.
3. Commit the source file together with the regenerated adapters.

## Add a skill
Create `.agents/skills/<name>/SKILL.md`. Claude Code and Cursor read it through symlinks, so nothing needs syncing.

## Generated (never edit by hand)
| Path | Kind |
|---|---|
| `.claude/rules`, `.claude/skills`, `.cursor/skills` | symlinks into `.agents/` |
| `.cursor/rules/*.mdc` | generated by the sync script |
